# Goal

Make the swap stage's rewritten filter cheap enough that very wide tables (5,000–10,000 columns) return it to genuine linear-pass territory, per issue #41: on the diagonal fixture the filter currently dominates the whole pipeline (~4.4 s of ~4.4 s), because each of the C same-name measurements pays for a sampled canonical projection and two frequency maps whose `expected` the filter never reads.

# Scope

`src/agreement.rs` (the new method), `src/swap.rs` (the filter's call site), `test-support/src/generate.rs` and `benches/pipeline.rs` (wide fixtures), `benches/README.md` (recorded timings), and `design.md` (wording). Deferred: putting the filter under a budget (issue #41's first question — the proportional purse already grows with C exactly as the filter does, so charging it changes no behavior at current defaults); native comparators for the binary family (a separate small step; the fallback covers them correctly); cross-representation fast paths (plan-next.md item 2); exposing budgets on the CLI.

# Design

The central invariants hold: reconciliation is unchanged, no event is inferred without evidence, and the cell-level diff is untouched — the filter's verdicts are bit-identical to today's, because the native arm rests on the codebase's standing invariant that native equality partitions values exactly as canonical equality does (the same argument `native_agreement` and `NativeHasher` already make, held to canonical values by the per-type digest tests). What changes is only what the filter pays per column: from "canonicalize + clone + hash 2 × sample values" to "sample array accesses and compares" for admitted same-type pairs, which in wide tables is almost all of them. The known regression is narrow and accepted: a table with many genuinely rewritten columns re-materializes those columns' sampled values at crossing time, because the native filter no longer warms the cache — small next to the wide-table win, and the right trade on the issue's numbers.

# Definition of done

On the regenerated diagonal and path fixtures, `swap::infer` is no longer the dominant stage and the recorded absolute times drop materially (target set by measurement, stated in `benches/README.md`); every existing test, including the demo transcripts, is byte-identical to `main`; the new unit tests pin native/fallback verdict equivalence, meter accounting, and cache behavior; and the full acceptance pass is clean.
